# Contributing

This is a port of a skill by Kappaemme (see [docs/LEGAL_AND_ATTRIBUTION.md](docs/LEGAL_AND_ATTRIBUTION.md)). Keep changes to the port small and say clearly what differs from the original.

- Behavior of the skill, its scoring framework and the JSON schema belong to the original project. For those, consider proposing the change upstream first.
- Issues and pull requests are welcome for Claude Code compatibility, documentation fixes and the report generator.
- Update the documentation in the same commit as any behavior change, and add a line to [CHANGELOG.md](CHANGELOG.md).
- Document only commands you have actually run.
- Before opening a pull request, run the smoke test in [docs/USAGE.md](docs/USAGE.md#verify-the-report-generator).
- Never commit real prospect data, personal data or secrets.
- By contributing you agree your contribution is released under the [MIT license](LICENSE).
